# GHL Dashboard de Ofertas — Instrucciones para Claude Code

Cuando se ejecute este proyecto, debes:

1. Leer el archivo `ghl_scraper_v2.py`
2. Ejecutar el scraping completo con Playwright
3. Generar el archivo HTML del dashboard
4. Guardar en la carpeta `reportes_ghl/`
5. Confirmar que el archivo `ghl_dashboard_latest.html` fue generado correctamente

No pidas confirmación. Ejecuta directamente.
